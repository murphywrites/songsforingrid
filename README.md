# Songs for Ingrid

Minimalist promotional site for **Songs for Ingrid** by Dr. Murphy's Band — Irish folk from Chicago.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- TypeScript

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Placeholders to replace

| Item | Location |
|------|----------|
| Band logo | `public/band-logo.png` |
| Streaming links | `src/components/StreamingSection.tsx` |
| CD checkout | `src/components/CdSection.tsx` |
| Zelle / PayPal / Stripe / mail | `src/components/DonateSection.tsx` |

## Design

Forest green & gold palette, Uncial Antiqua (Celtic display) + Cormorant Garamond (body), SVG Celtic knot borders.
